# Landing Page Specifications

The Landing Page represents the primary landing experience, targeting both prospective candidates and recruiters.

## Sections Outline

1. **Navigation Bar (Navbar):**
   * Responsive logo, links to features, FAQ, Pricing, Contact.
   * Dark/Light mode theme toggler button.
   * Call to action buttons: "Sign In", "Get Started".
2. **Hero Section:**
   * Bold value proposition: "AI-Powered Recruitment, Reimagined."
   * Modern animations, product dashboard preview.
   * High-contrast CTA buttons: "Apply as Candidate" and "Hire Candidates (Recruiter)".
3. **Product Features:**
   * Dynamic grid showcasing: AI Resume Parsing, Coding Assessment Sandbox, Kanban Board, Automated Interview Scheduler.
4. **How It Works / Recruitment Lifecycle:**
   * Interactive timeline mapping the journey from resume upload to contract signing.
5. **Testimonials:**
   * Interactive slider with recruiter endorsements and client success stories.
6. **Pricing / FAQ:**
   * Simple pricing cards (Free Tier, Pro Tier, Enterprise Tier) and toggling Accordion list.
7. **Footer:**
   * Copyright, social links, links to policies.

## Call to Action (CTA) Flows

```
Candidate CTA -> "/register" (Select Role: Candidate) -> Candidate Portal Dashboard
Recruiter CTA -> "/register" (Select Role: Recruiter) -> Recruiter Dashboard
```
