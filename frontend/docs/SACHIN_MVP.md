# MVP Priorities (Sachin's Scope)

Details the division of features across release phases (P0, P1, and P2).

## P0 — Core MVP (Must Have)
Features critical for the primary recruitment demo flow:
* **Landing Page:** Hero section and CTA buttons.
* **Authentication UI:** Secure Login and Registration forms.
* **Candidate Portal:** Upload Resume, Job List/Search, Apply, and Job Statuses.
* **Recruiter Dashboard:** Analytics, Kanban Board, Interview Scheduler, and Offers.

## P1 — Advanced Dashboard (Should Have)
Features that enhance user workflows:
* **Advanced Analytics:** Dynamic time-to-hire charts and department-based filters.
* **Global Search:** Platform-wide search for candidates, jobs, and applications.
* **Notifications Control:** System-wide notification management center.
* **Admin UI:** Basic user-role configurations.

## P2 — Future Scale (Nice to Have)
Features reserved for future updates:
* **AI Cover Letter Generator:** Automated cover letter drafts based on resumes.
* **Calendar Integrations:** Two-way sync with Google/Outlook calendars.
* **WebSocket Updates:** Real-time updates on pipeline stages and notifications.
