# HireLoop — AI-Powered Recruitment & ATS

DevFusion 4.0 — PS-2 — HRTech · AI · SaaS

An AI-powered Applicant Tracking System covering the full recruitment lifecycle — job posting, candidate applications, AI resume parsing & matching, interview scheduling, coding assessments, offer letters, and analytics.

## Team
- **Sachin Verma** — Frontend & Analytics
- **Shivam Kumar** — AI, Integration & Deployment
- **Muskan Mishra** — Backend & Workflow

## Tech Stack
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Node.js, Express
- Database: PostgreSQL / MongoDB
- AI: OpenAI API
- Deployment: Vercel (frontend), Railway/Render (backend)

## Project Structure

/frontend → Next.js app (Sachin)
/backend → Express API (Muskan)
/ai → AI service logic (Shivam)

## Setup
1. Clone the repo
2. Copy `.env.example` to `.env` and fill in values
3. `cd frontend && npm install`
4. `cd backend && npm install`
5. Run frontend and backend dev servers separately

## Branches
- `main` — production-ready only
- `develop` — integration branch, all features merge here first
